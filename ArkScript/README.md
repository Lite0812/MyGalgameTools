# ArkScript

- 引擎：ArkScript
- 测试游戏：《月の守》

## 文件

| 文件 | 用途 |
| --- | --- |
| `disassembler.py` | 将 BIN 脚本反汇编为可编辑文本。 |
| `assembler.py` | 将反汇编文本重新汇编为 BIN 脚本。 |
| `opcodelist.py` | 定义脚本 Opcode、参数和文本指令。 |
| `text_extract.py` | 从 BIN 脚本提取文本。 |
| `text_inject.py` | 将翻译文本回填到 BIN 脚本。 |
| `ArkScript-原说明.md` | 脚本格式和工具的详细说明。 |
