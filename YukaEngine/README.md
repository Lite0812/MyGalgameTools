# Yuka Engine

- 引擎：Yuka Engine
- 测试游戏：《らぶでれーしょん！》、《恋×恋＝∞ ～恋する乙女にできること～》

## 文件

| 文件 | 用途 |
| --- | --- |
| `yks_asm.py` | 对 YKS001 脚本进行汇编、反汇编、批处理和往返校验。 |
| `yks_text_plus.py` | 从加密或未加密的 YKS001 脚本提取 JSON 文本并回填。 |
| `analyze_clean_binary_similarity.py` | 分析 clean 模式重组脚本与原脚本的结构和字节差异。 |
| `patch_loose_files_first.ps1` | 修改指定版本 `LoveDere.exe`，使散文件优先于归档资源。 |
