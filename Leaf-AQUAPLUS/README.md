# Leaf / AQUAPLUS

- 引擎：Leaf / AQUAPLUS
- 测试游戏：《Tears to Tiara》

## 文件

| 文件 | 用途 |
| --- | --- |
| `sdt-tool/disassembler.py` | 将 SDT 脚本反汇编为可编辑文本。 |
| `sdt-tool/assembler.py` | 将反汇编文本重新汇编为 SDT 脚本。 |
| `sdt-tool/opcodelist.py` | 定义 SDT VM 的 Opcode 与参数。 |
| `sdt-tool/assemble_all.bat` | 批量汇编目录中的脚本文本。 |
| `sdt-tool/sdt_vm_analysis.md` | SDT 文件结构与 VM 分析。 |
