# Moonhir GSX1

- 引擎：Moonhir GSX1
- 测试游戏：《今日からプリンス》、《つまびっち！！》

## 文件

| 文件 | 用途 |
| --- | --- |
| `disassembler.py` | 将 GSX1/GKX 脚本反汇编为可编辑文本。 |
| `assembler.py` | 将反汇编文本重新汇编为 GSX1/GKX 脚本。 |
| `opcodelist.py` | 定义 GSX1 指令、值类型和参数结构。 |
| `fpk_tool.py` | 列出、解包、重建和校验 FPK 归档。 |
| `fbx_tool.py` | 解包、重建和校验游戏使用的 `FBX\x01` 压缩容器。 |
| `pageinfo_tool.py` | 导出、构建、比较和重新生成 PageInfo/IPT 文件。 |
| `vm_analysis.md` | GSX1 脚本 VM、外层容器和指令分析。 |
