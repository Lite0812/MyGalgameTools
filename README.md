# MyGalgameTools

平时拆游戏、改脚本时陆续攒下来的一些工具，有自己写的，也有在现成代码上改过的。

仓库里的工具主要用来解包和回包、导出和回填文本、处理图片与字体，以及给部分游戏做散文件加载或运行时 Hook。有些带图形界面，有些是 Python 命令行脚本，还有一些只保留了 C++ 工程，需要自己编译。

这些工具基本都是跟着具体游戏做出来的，目标是先把手头的问题解决，所以完成度并不统一，也不能保证同引擎的其他游戏直接就能用。每个目录的 README 都写了测试过的游戏和各个文件的用途，找工具时从对应的引擎目录进去看就行。暂时没确认引擎的，则按游戏名或文件格式单独放置。
