# Studio Mebius / MEBIUS34

- 引擎：Studio Mebius MEBIUS34
- 测试游戏：《めびにゃ！ -スタジオメビウスファンディスク-》

## 文件

| 文件 | 用途 |
| --- | --- |
| `mebius_txt_disasm.py` | 将 `SEENxxxx.TXT` 二进制脚本反汇编为可编辑文本。 |
| `mebius_txt_asm.py` | 将反汇编文本重新汇编为二进制脚本。 |
| `mebius_txt_op.py` | 定义 Opcode、操作数、表达式、文本流和重定位规则。 |
| `mebius_dialog_json.py` | 以 JSON 提取和回填对话、角色名与选项。 |
| `mebius_dialog_txt.py` | 以纯文本格式提取和回填对话。 |
| `mebius_gui.py` | 脚本与文本处理的 PyQt 图形界面。 |
| `MEBIUS34_TXT_opcode_analysis.md` | MEBIUS34 脚本结构、解释器和 Opcode 分析。 |
