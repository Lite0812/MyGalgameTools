# Macromedia Director

- 引擎：Macromedia Director
- 测试游戏：《sukisyo1》、《mizube_pk》

## 文件

| 文件 | 用途 |
| --- | --- |
| `current/cxt_tool.py` | 无损解包和重建包含文本 Cast 成员的 CXT 文件。 |
| `current/paige_xmed.py` | 解析、导出、修改和重建 Paige/XMED 富文本成员。 |
| `lingo-ls/director_ls_dialog_json.py` | 提取或回写 Lingo LS 脚本中的角色名与正文 JSON。 |
| `lingo-ls/director_ls_gui.py` | Lingo LS 文本处理图形界面。 |
| `lingo-ls/run_director_ls_gui.py` | 启动 Lingo LS 图形界面。 |
| `lingo-ls/director_ls_roundtrip.py` | 导出、修复文件名并回写 Lingo LS 脚本字面量。 |
| `lingo-ls/frida_dump_proj.py` | 通过 Frida 导出运行中的 `proj.dll` 及内存镜像。 |
| `TextHook/` | ONE 项目使用的 GDI 文本捕获与运行时替换工具。 |
