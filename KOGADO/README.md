# KOGADO

- 引擎：KOGADO
- 测试游戏：《Inugami》

## 文件

| 文件 | 用途 |
| --- | --- |
| `disassembler.py` | 反汇编 KGO 脚本并读取 `Scene.tbl`。 |
| `assembler.py` | 将语义汇编文本重新构建为 KGO 脚本。 |
| `opcodelist.py` | 定义 KGO Opcode、操作数和文本指令。 |
| `hypack_tool.py` | 列出、解包和重建 HyPack v0100、v0200、v0300、v0301 归档。 |
| `vm_analysis.md` | KGO 脚本 VM 与 HyPack 格式分析。 |
